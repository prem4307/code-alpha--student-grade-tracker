# 🎓 Student Grade Tracker - Notes

## 📌 About the Project

The **Student Grade Tracker** is a Java console application used to manage student records and grades. It helps users add students, record grades, calculate averages, assign letter grades, and display class statistics.

---

## 🎯 Project Objectives

* 👨‍🎓 Store student information
* 📝 Record multiple grades for each student
* 📊 Calculate average grades automatically
* 🏆 Assign letter grades
* 📈 Display student and class performance
* 🛡️ Validate user input

---

* ☕ Java
* 💻 Console Application

## 🏆 Grading Rules

| Average  | Grade |
| -------- | ----- |
| 90 - 100 | 🅰️ A |
| 80 - 89  | 🅱️ B |
| 70 - 79  | 🅲 C  |
| 60 - 69  | 🅳 D  |
| Below 60 | ❌ F   |

## 🛡️ Validation Rules

✅ Student IDs must be unique.

✅ Grades must be between **0 and 100**.

✅ Invalid grades are rejected.
